# Support

`Nikitka AI Travel` is a portfolio project, not a real travel agency.

## Use GitHub Issues For

- broken links;
- visible layout bugs;
- documentation corrections;
- demo behavior that does not match the README.

## Do Not Use Issues For

- real trip booking requests;
- visa, ticket, hotel, or travel support;
- API-key sharing;
- private security reports;
- requests to copy, rebrand, or reuse this project as a template.

For AI-provider setup, see [AI_SETUP.md](AI_SETUP.md).
